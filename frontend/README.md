# Kelly Poker Simulator — Frontend

React + Vite + Tailwind CSS + shadcn/ui frontend for the [Kelly Poker Simulator](../README.md)
(Part 10 of the project). See the root README's "Part 10: Frontend (React)" section for the full
write-up, architecture notes, and how this connects to the FastAPI backend.

## Setup

```bash
cp .env.example .env
npm install
npm run dev       # http://localhost:3000 (backend must be running on :8000, see root README)
```

## Scripts

```bash
npm run dev       # start the dev server
npm run build     # production build
npm run test      # run the Vitest suite once
npm run test:watch
npm run lint      # oxlint
```
